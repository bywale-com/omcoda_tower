## Resend’s permanent rejection is a type, not the event name

The event-type page at `https://resend.com/docs/webhooks/event-types`, fetched this session, says `email.bounced` occurs when the recipient’s mail server permanently rejected the email, and says `email.delivery_delayed` occurs when the email could not be delivered because of a temporary issue, with a full inbox or a transient receiving server as the examples. The bounced-webhook page says the same permanent sentence, and then its `bounce` object has `type` with examples `Permanent` and `Temporary`, plus `subType` and `message`. The sample payload’s type is `Permanent` and its subtype is `Suppressed`. The bounce-details page names three types. `Permanent` is the hard bounce. `Transient` is the soft bounce, and it may still be delivered. Its subtypes include `MailboxFull`. `Undetermined` is a bounce whose message did not contain enough to decide. The two pages use `Temporary` and `Transient` for the non-permanent arm. The suppression page says an address is added for origin `bounce` when the server permanently rejected it, and for origin `complaint` when the recipient marked it spam. `email.delivery_delayed` is not one of those origins. Its payload, on the delivery-delayed page, has `to` and has no `bounce` object.

That split is why the live mapper cannot be the suppress. A `Transient` bounce with subtype `MailboxFull` is `email.bounced`. `mapClass` would call it `bounce_hard`, claim 42 would silence the pair, and an address join on that class would suppress the mailbox for every firm. `deliv-10` bounds that retry. The subtype is not the class. `Permanent` stays hard even when the subtype is `Suppressed`. `Undetermined` is not the hard type the bounce page defines, so it is `bounce_soft`. A missing `type`, any other string, and an `email.bounced` with no `bounce` object stay `bounce_hard`, because the event-type sentence is the permanent rejection and the live mapper already emits that class for the whole event. The compare ignores case and surrounding space so the documented words match.
