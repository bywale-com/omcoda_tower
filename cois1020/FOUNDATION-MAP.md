# FOUNDATION-MAP — no exam syntax stays magic

**Lane:** FOUNDATION. Not examinable. Not mixed-exam content.

**Job:** What knowledge is *not necessarily on the test*, but must be constructed so that no exam syntax is an incantation.

**Law:** [`RULES.md`](./RULES.md) § Magic is forbidden. The PDFs define the **assessment** universe. This file defines the **explanatory** spine.

The **12 exam chapters stay**. Depth sits **under** them.

Cause the program first. Then refuse to let it remain a black box.
