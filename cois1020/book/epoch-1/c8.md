## 8.1 `char`

```csharp
char letter = 'r';
```

Single quotation marks. Table 2-1: system type Char, 2 bytes, Unicode, 0xFFFF / 0x0000.

Print `letter`.

**FOUNDATION:** a **character** is one Unicode code unit as this course uses `char` (Table 2-1: 2 bytes, Unicode). A **string** is a *sequence* of characters. `'r'` is one occupant; `"r"` is a sequence of length 1 — different types, different quotes. You do not need a Unicode encyclopedia. You need: one vs many, and why the quotes differ.

## 8.2 Table 2-5 — all of it

An **escape sequence** stores a pair of characters beginning with `\`. The pair is **one** character.

Construct at least `\\`, `\'`, `\n`, `\t` so you see they are not two letters of output.

Then **memorize the rest** of the table. Construction of four rows is not coverage.

| Sequence | Character name |
|---|---|
| `\'` | Single quotation mark |
| `\"` | Double quotation mark |
| `\\` | Backslash |
| `\0` | Null |
| `\a` | Alert |
| `\b` | Backspace |
| `\f` | Form feed |
| `\n` | Newline |
| `\r` | Carriage return |
| `\t` | Horizontal tab |
| `\v` | Vertical tab |

Chapter closed: recite sequence + name for every row.
