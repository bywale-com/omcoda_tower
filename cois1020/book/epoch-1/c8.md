## 8.1 `ReadLine` is a string

An **interactive** program accepts user input.

`Console.ReadLine()` reads until Enter. The result is a **string**. Always.

```csharp
string name;
Console.Write("Enter your name : ");
name = Console.ReadLine();
Console.WriteLine("Your name is {0}", name);
```

Fix the slide’s missing quote if you copy carefully: the format string must close before the comma.

## 8.2 Convert, then compute

You must convert the string:

```csharp
itemPrice = Convert.ToDouble(itemPriceAsString);
```

or nested:

```csharp
itemPrice = Convert.ToDouble(Console.ReadLine());
```

A **named constant** uses `const`. It cannot change. Convention: `ALL_CAPS` with underscores.

```csharp
const double TAX_RATE = 0.06;
```

## 8.3 Self-documenting

```csharp
const int INCHES_IN_A_FOOT = 12;
lengthInches = lengthFeet * INCHES_IN_A_FOOT;
```

That statement is **self-documenting**: readable without a comment. Use a `const` in your program so you do not multiply by a bare magic number.
