## 10.1 `ReadLine` is a string

**Interactive** = allows user input.

`Console.ReadLine()` reads until Enter. Characters assign to a **string**. The PDF: **all input is by default read as a string.** You must convert to the proper type.

```csharp
string name;
Console.Write("Enter your name : ");
name = Console.ReadLine();
Console.WriteLine("Your name is {0}", name);
```

(Close the format string before the comma.)
