## 3.1 Declare and show

A **variable** is a named location in memory that can hold different values at different times.

A **literal constant** is a value written as itself (`39.45`, `"hello"`). It cannot change after compile.

A **data type** describes format, size, and allowed operations.

**Declaration** names the variable and reserves storage.

Type this shape (your names, same idea):

```csharp
double someMoney = 39.45;
Console.WriteLine(someMoney);
```

Predict the output. Run. Write whether the `$` appeared (it should not — you did not print it).

### Foundation — read the line (not on this test as extra terms)

| Token | Role |
|---|---|
| `double` | **type** — what kind of value this place can hold |
| `someMoney` | **identifier** — the variable’s name |
| `=` | **initialization** (here): put this value into the new place |
| `39.45` | **literal** — a value written as itself |
| `;` | statement terminator |
| the whole line | **declaration + initialization** in one statement |

These are three different constructions:

```csharp
double someMoney;        // declaration only — named place, no value yet
someMoney = 39.45;       // assignment — fill (or refill) an existing place
double someMoney = 39.45; // declaration and initialization together
```

**Variable** = the named place (can hold different values at different times — EXAM).  
**Value** = what is in the place right now.  
**Type** = the kind of value allowed.  
A **statement** is an instruction (`;`). An **expression** produces a value (`39.45`, `someMoney`, later `x + y`).

Useful grain of memory: the name refers to a location; the type decides the size/format of what fits there. You do not need a hardware course.

## 3.3 Placeholder

A **format string** is ordinary text plus **placeholders**.

A **placeholder** is `{n}` — `n` is the position in the list of values **after** the string (`{0}` first, `{1}` second).

```csharp
Console.WriteLine("The money is ${0} exactly", someMoney);
```

Predict. Run.

Then three integers, width 5:

```csharp
int num1 = 4, num2 = 56, num3 = 789;
Console.WriteLine("{0, 5}", num1);
Console.WriteLine("{0, 5}", num2);
Console.WriteLine("{0, 5}", num3);
```

Predict whether they right-align. Run. `{0, 5}` is a placeholder with **alignment**.
