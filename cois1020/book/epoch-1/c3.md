## 3.1 Declare and show

A **variable** is a named location in memory that can hold different values at different times.

A **literal constant** is a value written as itself (`39.45`, `"hello"`). It cannot change after compile.

A **data type** describes format, size, and allowed operations.

**Declaration** names the variable and reserves storage.

Type this shape (your names, same idea):

```csharp
double someMoney = 39.45;
Console.WriteLine(someMoney);
```

Predict the output. Run. Write whether the `$` appeared (it should not — you did not print it).

Declare two `int`s two ways:

- two statements
- one type, two names, comma: `int num1 = 4, num2 = 56;`

## 3.2 `Write` vs `WriteLine`

```csharp
Console.Write("The money is $");
Console.WriteLine(someMoney);
```

Predict the **exact** console text, including whether there is a line break in the middle. Run. Write what happened.

`Write` continues on the same line. `WriteLine` ends the line.

## 3.3 Placeholder

A **format string** is ordinary text plus **placeholders**.

A **placeholder** is `{n}` — `n` is the position in the list of values **after** the string (`{0}` first, `{1}` second).

```csharp
Console.WriteLine("The money is ${0} exactly", someMoney);
```

Predict. Run.

Then three integers, width 5:

```csharp
int num1 = 4, num2 = 56, num3 = 789;
Console.WriteLine("{0, 5}", num1);
Console.WriteLine("{0, 5}", num2);
Console.WriteLine("{0, 5}", num3);
```

Predict whether they right-align. Run. `{0, 5}` is a placeholder with **alignment**.
