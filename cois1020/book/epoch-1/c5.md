## 5.1 Binary and unary

**Binary** operators take two operands: `z = x + y`.  
**Unary** take one: `z = -x`.

```csharp
int x = 8, y = 9, z;
z = x + y; // predict
z = -x;    // predict
```

Also use `*`, `/`, `%` (remainder) on small integers you chose. Predict remainder of `10 % 3` before you run.

## 5.2 Precedence

`*`, `/`, `%` bind tighter than `+`, `-`. Parentheses override.

Predict, then print:

```csharp
int a = 3 + 4 * 2;
int b = (3 + 4) * 2;
```

If your predictions were left-to-right for both, write that. Then write the rule.

## 5.3 Shortcuts

`total = total + val` is `total += val`. Also `-=`, `*=`, `/=`.

**Increment:** `++someValue` (prefix) and `someValue++` (postfix). Decrement: `--`.

They differ when the value is **used in the same statement**.

```csharp
int n = 5;
Console.WriteLine(n++); // predict the printed number AND n after
n = 5;
Console.WriteLine(++n); // predict
```

Do not skip the prediction. The test likes this.
