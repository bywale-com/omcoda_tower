## 9.2 Equals, Compare, CompareTo

- `Equals` — same value? → **Boolean**. `String.Equals(Str1, Str2)`.
- `Compare` / `CompareTo` → **integer**:
  - **negative** — first precedes second in sort order
  - **zero** — same position, or the length is zero (slide’s wording)
  - **positive** — first follows second

```csharp
string s1 = "Alaa";
string s2 = "John";
Console.WriteLine(s1.CompareTo(s2));
Console.WriteLine(String.Compare(s1, s2));
```

Predict **−1** and **−1** (the slide’s output). Run.

**FOUNDATION — not on this test, but magic is forbidden if you type these:**

```text
String.Equals(s1, s2)     type
        . Equals          static method on the String type
        (s1, s2)          arguments

s1.CompareTo(s2)          value/object
        . CompareTo       instance method on that string
        (s2)              argument

s1.Length                 value/object
        . Length          property — information exposed, not a call
                          hence no ()
```

A **static method** belongs to the **type** (`String.Equals`, `String.Compare`, `Console.WriteLine`). An **instance method** belongs to a **particular value/object** (`s1.CompareTo`).

A **method** is called: `(...)`. A **property** is accessed as information: no `()`. `Length` is a property. `Substring` is a method (`Substring(0, 2)`).

The `.` is still member access (C0). The thing on the left is either a type or a value; that is the static/instance split.

**EXAM** still: Equals → Boolean; Compare/CompareTo → negative / zero / positive; Length of `"water"` is 5.

## 9.4 Substring — the figure, including the X marks

`Substring()` extracts from a **starting point** for a **specific length**. `"water"` positions 0 1 2 3 4.

The figure’s first three (construct these). Positions are **zero-based** (FOUNDATION: the first character is at 0, which is why `"water"`’s last index is 4, length 5):

```csharp
word.Substring(0, 1)  // "w"
word.Substring(0, 2)  // "wa"
word.Substring(1, 2)  // "at"
```

The figure marks these two **wrong**:

```text
word.Substring(2, word.Length - 1)  is "ter"    ✗
word.Substring(0, word.Length - 1)  is "water"  ✗
```

Do not memorize the X’d claims as true. Memorize that the slide marked them wrong.
