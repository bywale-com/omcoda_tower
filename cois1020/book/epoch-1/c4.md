## 4.1 Integral vs floating

**Integral types** store whole numbers. Memorize the nine:

`byte`, `sbyte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`, `char`

(`char` is on this list on the slide even though you will use it as a character in C7.)

**Floating-point** numbers contain decimal positions:

| Type | Slide claim |
|---|---|
| `float` | Up to seven significant digits |
| `double` | Default. 15 or 16 significant digits |
| `decimal` | More precision, smaller range. Money. |

## 4.2 Suffixes — feel the compiler

Predict, then paste each line into a throwaway method (or comment them one at a time):

```csharp
float val = 54.7;     // the slide says incorrect
float val = 54.7F;    // correct
decimal wage = 12.55; // incorrect
decimal wage = 12.55M;// correct
```

Write why the first and third fail: a literal with a decimal is `double` by default. **`F`** makes `float`. **`M`** makes `decimal`. **`D`** makes `double` (optional, because it is the default).

## 4.4 Format specifiers

C# prints floating values concisely unless you ask otherwise. Standard numeric format strings look like `{0:F1}` — a **format specifier** plus optional **precision**.

Build a demo in the spirit of the slide (`val = 34.456`, then `23456.78`):

| Spec | Meaning |
|---|---|
| `{0}` | default |
| `{0:F}` | fixed point |
| `{0:F1}` | fixed, 1 digit after decimal |
| `{0:F3}` | fixed, 3 digits |
| `{0:E}` | scientific |
| `{0:C}` | currency |
| `{0:C3}` | currency, 3 digits |

Predict the **rounded** `F1` of `34.456` before you run. Then run. Write the seven lines you got.
