## 7.2 Table 2-4 — every operator

A **comparison operator** compares two items. The expression has a **Boolean** value.

The PDF’s table (true example and false example). Predict each, then print:

| Operator | true example | false example |
|---|---|---|
| `<` | `3 < 8` | `8 < 3` |
| `>` | `4 > 2` | `2 > 4` |
| `==` | `7 == 7` | `3 == 9` |
| `<=` | `5 <= 5` | `8 <= 6` |
| `>=` | `7 >= 3` | `1 >= 2` |
| `!=` | `5 != 6` | `3 != 3` |

Do not skip rows because they “feel obvious.” The table is the exam surface.
