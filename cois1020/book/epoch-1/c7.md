## 7.1 `bool` and comparison

A **Boolean** variable is `true` or `false`:

```csharp
bool done = true;
```

A **comparison operator** produces a Boolean. Use at least one (`==`, `!=`, `<`, `>`, `<=`, `>=` as you need).

```csharp
int a = 3, b = 5;
bool less = a < b;
Console.WriteLine(less);
```

Predict `true` or `false` before Run.

---

## 7.2 `char` and escapes

`char` holds **one** character. Use **single** quotes:

```csharp
char letter = 'r';
```

An **escape sequence** is a backslash pair that counts as one character (`\n` newline, `\t` tab, `\\` backslash, `\'`, `\"`).

Print a char, then a string that contains `\t` or `\n`, so you see the escape is not two letters of output.

## 7.3 `string`

A **string** is a series of characters in **double** quotes:

```csharp
string name = "Richard";
```

Compare with `==` / `!=`, and with the methods the slide names:

- `Equals` — same value? → `bool` (`String.Equals(s1, s2)` or instance)
- `Compare` / `CompareTo` — integer:
  - **negative** — first precedes second in sort order
  - **zero** — same (or empty length case as the slide)
  - **positive** — first follows second

Reproduce the slide’s idea:

```csharp
string s1 = "Alaa";
string s2 = "John";
Console.WriteLine(s1.CompareTo(s2));
Console.WriteLine(String.Compare(s1, s2));
```

Predict **negative** before you run (`Alaa` before `John`).

**Length:** `"water"` has length **5**. Print `yourWord.Length`.

**Substring:** extract from a start index for a length. Pick a word; extract a piece; print it. (If the exact `Substring` overload is fuzzy, look once at IntelliSense, then write the call from memory the second time.)
