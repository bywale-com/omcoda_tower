## 11.1 `const`

A **named constant** is an identifier whose contents cannot change. Keyword `const`.

Replace the ordinary rate with:

```csharp
const double TAX_RATE = 0.06;
```

Usually **ALL_CAPS** with underscores. Also the slide’s inches example:

```csharp
const int INCHES_IN_A_FOOT = 12;
```

Predict the compile error, then try `TAX_RATE = 0.07;` after declaration. Restore.

The tax multiply now uses `TAX_RATE`, not a variable you could reassign.
