## 11.1 `const`

A **named constant** is an identifier whose contents cannot change. Keyword `const`.

```csharp
const int INCHES_IN_A_FOOT = 12;
```

Usually **ALL_CAPS** with underscores.

Predict the compile error, then try assigning after declaration. Restore.

Keep a working tax-or-inches program that uses `const` (not a bare magic number in the multiply).
