## 1.1 Identifiers vs keywords

Form this intention: the **class** should have a name you chose; `Main` must stay `Main`.

The slides’ rules for a name you choose (**identifier**):

- Starts with `_`, `@`, or a letter

- Must not be a reserved **keyword**

### After you have felt that

Words the compiler already owns are **keywords** (`public`, `static`, `void`, `class`, `using`, …). Names you choose are **identifiers** (class name; later, variable names).

The PDF: **every console application must have a `Main()` method.** The method returns nothing as indicated by the keyword **`void`**. That is the whole claim. Do not add a “host looks for Main” story.

Table 1-1 on the PDF is the reserved-keyword list. You do not chant it. You **recognize** a word from it (`class`, `int`, `public`) as illegal for a name you choose.

## 1.2 Access, header, body, whitespace

Label, in comments or in notes, these on your program:

- **Access modifier** — `public` (when the method can be accessed)
- **Method header** — `public static void Main()`
- **Method body** — everything in the `{ }` of `Main`
- `void` — this method returns nothing
- **Namespace** — `System` is a grouping of classes (the slides’ “toolbox”)
- **`Console`** — the class for standard input/output/error
- **`WriteLine`** — the method
- **Argument** — the literal string

Add blank lines and spaces (**whitespace**). Predict: does the output change? Run. Write what happened.

Whitespace organizes reading. It does not change meaning, except inside a string.

## 1.3 Comments

**Line comment:** `//` to the end of the line.  
**Block comment:** `/* … */`.

Add a file-header (filename, your name, date) with `//`. Add a block comment stating what the program does. **Comment out** the `WriteLine` (turn it into a comment). Predict: compile? Output? Run. Restore.

Comments are non-executing. Comment-out is how you disable a statement without deleting it.

## 1.4 `using System;`

The slides show two equivalent programs.

**Without** `using`: `System.Console.WriteLine(...)`.  
**With** `using System;` at the top: `Console.WriteLine(...)`.
