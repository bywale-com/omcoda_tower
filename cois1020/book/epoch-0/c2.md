## 2.1 Syntax error vs logic error

**Experiment A — syntax.** Misspell `WriteLine` as `WriteLn`. Predict: run with wrong text, or refuse to compile? Do it. Write the result. Restore.

**Experiment B — logic.** Compile a program that runs and prints the **wrong** sentence (you meant your name; you wrote someone else’s, or you wrote three lines in the wrong order). Predict: will Visual Studio treat this as an error? Run. Write the result. Restore.

### After you have felt that

**Syntax** = rules of the language. A **syntax error** is a break in those rules. The compiler stops you.

**Programming logic** = executing statements in the correct order to get the intended result. A **logic error** can compile and still be wrong.

**Debugging** = removing **all syntax and logical errors**.

## 2.3 Machine vs high-level

The slides contrast:

```csharp
int x = 5;
int y = 3;
int sum = x + y;
```

with bytes like `10111000 00000101`. You do **not** write the bytes. You do not need those exact bytes. You need the distinction:

- **Machine language** — 1s and 0s (switches on/off). The computer’s language.
- **High-level language** — terms such as read / write / add. Has **syntax**. C# is this.

A **compiler** (also: interpreter, assembler — different translators) turns program statements toward machine language.

C#’s path on the slide:

1. Compile source to **intermediate language (IL)**
2. **JIT** (just in time) compiler turns IL into machine code that this CPU executes

Visual Studio is the **IDE** the course uses. Slide advantages: scaffolding, color, double-click an error to jump to the line, debugging tools. Command-line Linux is “not for us.”

Write in notes, in your words, the two-step path (IL, then JIT). Do not paste the slide.

## 2.4 Software categories, C#, procedural vs OO

Say, then check against the PDF:

- **Application software** — a user’s job (the programs you are writing are this).
- **Procedural** — create named memory locations (variables — named here, built in C3) and a series of steps; **methods** group operations and get invoked.
- **C#** — object-oriented; in Visual Studio; modeled after C++; similar to Java syntactically; drops some of C++’s hardest features.
