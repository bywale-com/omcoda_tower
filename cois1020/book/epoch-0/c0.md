## 0.3 Read the outer shell

```csharp
public static class Lab1
{
    ...
}
```

**FOUNDATION — not on this test as extra vocabulary, but you must own it.**

A **class** is a named type: a blueprint the program uses to group related members (here: one method). Declaring a class is writing that blueprint.

- `class` — “what follows is a class.”
- `Lab1` — the class **name** (an identifier you chose). The class is not the file. The class is not “the program” by itself. The **program** is the whole application; this class is the type that currently *contains* the starting method.
- `{ }` after the class name — the **class body**. Nesting: what is inside belongs to this class.
- `public` — an **accessibility** word: other code is allowed to see this type. **Public to whom?** To code outside this class / this compilation unit, in the language’s accessibility rules.
- `static` on the **class** — a particular kind of class: you do not make an object of it with `new`; it can contain only static members. Useful sometimes. **A console app’s containing class does not have to be `static`.** The slide wrote it. That does not make it what *starts* the program.

**EXAM shape you must still recognize/write:** `public static class ...` as on the lab slide.

## 0.4 Read the starting behavior

```csharp
public static void Main()
{
    ...
}
```

A **function** (general idea): named executable behavior, possibly receiving inputs and returning an output.

C# normally calls executable members on types **methods**. A method is a function that **belongs to a type**.

- `Main` — method **identifier**. **EXAM:** every console application must have a `Main()` method.
- `void` — **EXAM:** the method returns nothing.
- `( )` — **parameter list**. Empty here: this `Main` is not declared to receive inputs in the source you wrote.
- `{ }` — **method body**: the statements that run when `Main` runs.
- `public` on `Main` — accessibility of this method.
- `static` on `Main` — **this is the important distinction in the classic model.**

**FOUNDATION — instance vs type:**

An ordinary (instance) method conceptually needs an object:

```text
make object
    ↓
call method on that object
```

A **static** method belongs to the **type** itself:

```text
type
 ↓
call static method
```

The application needs somewhere to begin **before** you have created a `Lab1` object. So the traditional **entry point** is static.

`public` on the class is **not** what makes it “the program.” `static` on the class is **not** either. **`static` on `Main` is.**

## 0.5 Read one instruction

```csharp
System.Console.WriteLine("Hello COIS1020H, my name is xxx");
```

| Token | Meaning |
|---|---|
| `System` | a **namespace** (a grouping of types — the slides’ toolbox) |
| `.` | **member / qualification** access: “look inside the thing on the left” |
| `Console` | a **class/type** inside `System` |
| `.` | member access again |
| `WriteLine` | a **method** belonging to `Console` |
| `(` | begin **argument list** (values you pass in) |
| `"..."` | **string literal** — the argument **value** |
| `)` | end argument list |
| `;` | **statement terminator**. This whole line is one **statement** (one instruction). |

`WriteLine(...)` **calls** the method. The parentheses are the call. What you put inside is an **argument**. A **parameter** is the placeholder the method is declared to receive; an argument is the actual value you supply at the call.

**EXAM:** the quoted text is a **literal string**; it is an **argument** to `WriteLine`.

Same reading for `System.Console.ReadLine();` — call `ReadLine` on `Console` with an empty argument list.
