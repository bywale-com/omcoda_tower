# DESTINATION — this test

Sit a COIS1020H assessment whose **only** sources are:

- Chapter 1 — A First Program Using C#
- Chapter 2 — Using Data

and not freeze.

Graduation for this folder is not “knows C#.” It is:

```
I can write a console program with Main from a blank file.
I can name every part of that program the way the slides name it.
I can say how source becomes machine code (IL, JIT).
I can declare, display, compute, convert, and read values.
I can pick int / double / decimal / bool / char / string on purpose.
I can tell syntax error from logic error.
I can answer the slides’ True/False and fill-ins without the PDF open.
```

When the test is over, move this folder out of the Tower repo. It is not part of Tower Construction.
